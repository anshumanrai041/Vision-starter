# Color Space Converter and Histogram Analysis

A simple Computer Vision project built with Python, NumPy, and Matplotlib.

## Features

- Generate a synthetic RGB image
- Extract Red, Green, and Blue channels
- Convert RGB image to Grayscale
- Compute channel histograms
- Visualize image data and histogram distributions

## Requirements

- Python 3.15
- NumPy
- Matplotlib

## Installation

pip install \-r requirements.txt

## Run

python color\_space\_converter/main.py

## Concepts Demonstrated

- RGB Color Space
- Grayscale Conversion
- Meshgrid Generation
- Histogram Analysis
- NumPy Array Operations
- Data Visualization
